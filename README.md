# Amazon E-Commerce SQL Analysis

## Project Overview

This project focuses on analyzing an Amazon e-commerce dataset using SQL.

The dataset contains information about customers, products, orders,
order items, payments, shipments, and returns.

The project covers intermediate to advanced SQL case-based analysis,
including financial analysis, customer behavior, ranking, time series,
operational logistics, and e-commerce business logic.

## Database

MySQL

## Tables

- Customers
- Products
- Orders
- OrderItems
- Payments
- Shipments
- Returns

## Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- Git
- GitHub

## Project Goals

- Perform advanced SQL analysis
- Analyze sales and profitability
- Understand customer behavior
- Perform RFM and cohort analysis
- Analyze shipping and operational performance
- Solve complex business case-based SQL problems
- Generate actionable business insights
